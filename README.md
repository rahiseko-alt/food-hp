# cc-v2

開発用のテンプレートリポジトリ。新しい案件は、このリポジトリをコピーして始める。

## 使い方

1. このリポジトリをコピーする（GitHub の "Use this template"、またはクローンして別リポジトリとして push）。
2. コピーしたリポジトリを開き、AI コーディングツールでセッションを開始する。
3. 以降の進め方は `AGENTS.md` に従う。既にプロダクトのコードがあれば「取り込み」、まだ無ければ
   「ゼロから始める場合の初期化フロー」に入る。
4. `main` の branch protection はコピーで運ばれないので、コピー先で1回だけ設定する
   （`AGENTS.md`「機械強制の有効化」、または `bash scripts/setup.sh`）。

同梱の `apps/web` / `packages/ui` は鉄板構成のサンプル。使わない場合は取り込みの手順で削除する。
