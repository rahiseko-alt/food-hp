# <パッケージ名 / 案件名> の AGENTS.md（雛形）

**モノレポで package ごとに構成が違う場合に使う。** 単一プロダクトならこのファイルは使わず、
ルート `AGENTS.md` の「このプロジェクト」欄を埋めれば足りる。

このファイルを対象ディレクトリ直下にコピーし、そのディレクトリ配下にだけ効くスタックを書く。
ルートの普遍ルールは自動で継承されるので、**ここには「そのディレクトリのスタック」だけ**書く。

> **既にコードがある場合**：ルート `AGENTS.md`「取り込み」に従い、現状のスタックを
> （「決める」のではなく）そのまま下の欄に記載する。CI・ワークフローの書き換えや同梱サンプルの
> 削除も、そちらの手順に含まれる。
> **コードがまだ無い場合**：ルート `AGENTS.md`「ゼロから始める場合の初期化フロー」の手順1〜5
> （ヒアリング→リサーチ→提案→承認→設定）で決めてから、下の欄を埋める。
>
> **機械強制の有効化（新しいリポジトリで1回だけ）**：手順はルート `AGENTS.md`「機械強制の有効化」を
> 参照（要点：リポジトリを Public にし、`ci-green` を main の branch protection で必須化する）。
> エンジニアは `bash scripts/setup.sh` でも可。
